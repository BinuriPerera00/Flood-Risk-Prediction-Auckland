# Flood-Risk-Prediction-Auckland


This repository contains the implementation and supporting materials for the Master's dissertation:

**“Flood Risk Prediction using Machine Learning: A Case Study of Flood Risk in Auckland”**

Submitted to:
Auckland University of Technology (AUT), 2026


## Project Overview

This research develops a region-specific and explainable machine learning framework for urban flood prediction across multiple Auckland regions using hydrological, meteorological, and temporal environmental variables.


## Study Regions

- Central Auckland
- Albany
- Henderson
- Manukau


## Dataset Source

The datasets used in this study were obtained from the Environment Auckland Data Portal.

Included datasets:
- Albany.csv
- central.csv
- Henderson.csv
- manukau_full.csv
